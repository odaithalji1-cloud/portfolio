# Odai Ahmad — Portfolio

Personal portfolio for **Odai Ahmad**, Backend & AI Engineer.

A static, dependency-free site (plain HTML, CSS and JavaScript) with:

- Dark / light theme (follows the system, remembers your choice)
- Sections: About & tech stack, What I do, Journey timeline, Projects (filterable), Contact
- Responsive layout and scroll-reveal animations (respects reduced motion)

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

## Deploy

No build step. Point Netlify / GitHub Pages / Vercel at the repository root
(publish directory: `.`).

## Editing content

All content lives in `index.html` — update the experience timeline, projects
and contact links there.
